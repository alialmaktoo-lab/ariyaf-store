# متجر أرياف ARIYAF — نسخة ثابتة

واجهة عربية بسيطة للشاي والقهوة تعمل دون خادم خلفي أو قاعدة بيانات. يختار العميل المنتجات والكميات، ثم يفتح واتساب برسالة طلب جاهزة. لا يحفظ الموقع الطلبات؛ يجب على العميل الضغط على إرسال في واتساب.

## قبل النشر
1. افتح `assets/app.js` واستبدل `968XXXXXXXX` برقم واتساب المتجر الحقيقي مع رمز الدولة، أرقام فقط.
2. افتح `assets/products.js` واستبدل أسماء المنتجات والأوصاف والأسعار المؤقتة بالبيانات الصحيحة.
3. الصور الحالية رموز تعبيرية مؤقتة؛ يمكن استبدالها بصور المنتجات لاحقًا.
4. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub أو مجلد مخصص للنشر.

## نشر GitHub Pages
- إذا كانت الملفات في جذر المستودع: من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)`.
- إذا كانت داخل مجلد `docs`: اختر `main` و`/docs`.
- انتظر اكتمال النشر من صفحة Pages.

لا توجد حاجة إلى Node.js أو API أو قاعدة بيانات لهذه النسخة. الأسعار الافتراضية أمثلة فقط ويجب مراجعتها قبل النشر.
